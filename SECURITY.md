# Security policy

Please report suspected security issues privately. When private GitHub security reporting is enabled for this repository, use it instead of opening a public issue.

Do not include clipboard contents, passwords, API keys, access tokens, personal information, or other credentials in a report. Describe the behavior with redacted or synthetic examples, plus the ClipHaven version and macOS version when available.

ClipHaven can retain supported clipboard text and images in an unencrypted local history file. This is expected behavior, but an unexpected capture, retention, access-control, or automatic-paste behavior should be reported as a security concern. Do not attach the history file or its real contents to a report.

If private reporting is not enabled, do not publish sensitive details in an issue. Ask the repository owner for a private reporting channel first.
